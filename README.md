🌐 Personal Portfolio Website

A modern, responsive, and animated **personal portfolio website** built using **HTML, CSS, and JavaScript**.  
This project showcases my skills, projects, and contact information in a clean and professional way.

## 🚀 Features

✅ Responsive design (Desktop & Mobile friendly)  
✅ Smooth scroll & scroll-reveal animations  
✅ Typewriter text animation  
✅ Modern UI with glassmorphism navbar  
✅ Animated hero section with floating card & blob  
✅ Project showcase cards with hover & tilt effects  
✅ Dark & Light theme toggle  
✅ Clean and professional layout  
✅ Pure HTML, CSS & JavaScript (no frameworks)

---

## 🛠️ Tech Stack

- **Frontend:**  
  - HTML5  
  - CSS3 (Animations, Flexbox, Grid)  
  - JavaScript (Vanilla JS)

- **Design:**  
  - Modern UI/UX  
  - Gradient & micro-animations  
  - Responsive layout
